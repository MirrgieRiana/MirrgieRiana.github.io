# wooden-tools

各ツールの詳細は、各ツールのソースコードを参照してください。

- `cat.sh` - 任意の場所のファイルを自由に読み取るためのcatコマンドのラッパーです。
   - ただし、決して、認証情報等の機密情報類に対して呼び出してはいけません。
- `ls.sh` - 任意の場所のファイルの一覧を自由に得るためのlsコマンドのラッパーです。
- `jq.sh` - 任意のJson加工、データ加工、計算処理、ループ等ができる万能のツールです。
- `claude-log-parser.sh` - Claude Codeの会話ログのjsonlファイルを見やすく整形します。
- `compress-text.sh` - 会話のログ等に出現する反復部分を圧縮し、可読性を上げるツールです。
