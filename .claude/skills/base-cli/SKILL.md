# base-cli

## 承認ダイアログの最小化

承認ダイアログが発生すると、あなたの動作は永続的にブロッキングされ、再開にはユーザーによる判断と入力操作が必要になります。
また、承認ダイアログが発生した際に自動的に拒否をする設定がなされている場合、そもそもそれは実行できません。
あなたは、ツールを使用する際は、承認ダイアログの発生を最小限にするように、工夫しなければなりません。

## 情報収集

### 強欲な情報収集

**情報収集は、ユーザーが閲覧禁止を指示していない限り、認証情報などの機密情報に類するものを除いて、強欲に行ってください。**

機密情報は、通常、明らかに閲覧してはいけなそうな場所に置かれています。
あなたが閲覧をしてよいか悩むような場所には、あなたが閲覧してはならない情報はありません。

「続きを読みますか？」といった無益な質問で、貴重な人間の労力をかけさせないでください。
あなたは、目の前の資料の閲覧の努力を渋り、中途半端な知識に基づいて、信頼性の低い発言をしてはいけません。

## ファイルシステム

`/mnt/c/...` といった、Windows 上のファイルシステムに対する chmod は、何の効果もないことを、理解しなければなりません。
それをそのまま git add しても、実行可能フラグはコミットされません。

## 一時作業用ディレクトリ

### claude_tmp

claude_tmp のパスは、`~/.claude_tmp/{あなたのセッション ID}` です。
`{あなたのセッション ID}` の部分は、適切に埋めてください。
当該ディレクトリは自動で作成されないため、claude_tmp の利用の際は、あなたが自分で作成してください。

claude_tmp への読み書きの権限は、事前に付与されています。
claude_tmp への書き込みに失敗した場合、その理由は、claude_tmp への書き込み権限以外の部分にあります。

`~/.claude_tmp/share/` 以下には、複数のセッションで利用するための公共のファイルを置くことができます。

あなたにチケット制が適用されている場合は、この条文により、`~/.claude_tmp/{あなたのセッション ID}` への改変操作が許可されます。＄

`~/.claude_tmp/git/` 以下には、複数のセッションで共有すべき git リポジトリを置くことができます。
現在のワークスペースと異なる git リポジトリを取得する際は、ここの利用を検討してください。
また、現在のワークスペースが権限によって保護されている場合にも、あなたが自由に操作できるリポジトリスペースとして利用できます。

### .gitignore に登録されたパス

プロジェクトごとの事情に準じ、その目的にのみ使用してください。

## memory

### セッション固有の memory の利用

`~/.claude_tmp/{あなたのセッション ID}/memory/` 以下に、セッション固有のメモリーを記述してください。
そこには、ユーザーの指示や判明したことなど、コンパクションをまたいで残すべき情報を、頻繁に追記してください。

## 編集

### 自発的な改変の禁止

あなたは、ユーザーから、明示的かつ直接的に命令を受けない限り、以下のような、本質的に改変を意図した操作を行ってはなりません。

- ファイルやディレクトリ等の作成、編集、属性の変更、削除等
- サーバーやリモートマシンに対して、内部状態の変更を目的とした操作
- 読み取り専用でないコマンドの実行

代わりに、本質的に閲覧である操作のみを行ってください。

---

ユーザーの発言を注意深く読んでください。
質問や指摘や批難は、命令ではありません。

### 命令の範疇外の改変の禁止

あなたは、ユーザーの命令に従って編集を行う際に、命令の範疇から外れる改変を、勝手に導入してはいけません。
決して、編集のついでに、無関係な部分の編集を行ってはいけません。
決して、編集のついでに、命令にない機能の追加を行ってはいけません。
決して、編集のついでに、余計なリファクタリングや、コメントやフォーマットの修正を行ってはいけません。
あなたが良かれと思って追加した余計な差分を、あるべき状態に戻すだけのために、ユーザーの貴重な労力を奪わないでください。

## 会話

ユーザーに返答する際は、提出物だけを出してはならず、必ず返答のメッセージを添えなければなりません。

ある程度長い作業を終えたら、toast-wsl.sh によって、通知を送信してください。
その際、メッセージはあなたの口調で記述してください。
