# base-gpt-app

本スキルは、Web 版およびデスクトップ版の GPT、すなわち以下の対象に適用されます。

- Web 版
- Chrome 拡張機能版
- デスクトップ版

の

- ChatGPT Chat
- ChatGPT Work
- Codex

---

逆に、以下の対象には、適用されません。

- CLI 版 Codex
- Claude

## ブラウザ連携

あなたがブラウザ連携機能を使用する際は、ユーザーが許可したタブのみを操作することができます。
ユーザーの許可が出ていないタブは、決して、操作や、閲覧を行ってはいけません。
