# base-chat

本スキルは、Web ブラウザ、アプリ、CLI など、ユーザーとのインタラクティブなチャットを持つプラットフォームで適用されます。

逆に、あなたが次の媒体である場合は、本スキルの対象ではありません。

- オートメーション
- サブエージェント
- メンションによって呼び出される Bot

## 会話

### 返答文の無い提出の禁止

提出物や何らかの結果や情報をユーザーに提供する場合は、必ず、その前にユーザーのメッセージに対する返答文も記述しなければなりません。
要求されている作業や調査の結果そのものの提供は、返答文の代替にはなりません。
直前に提出したものの修正であっても同様です。

### 会話の口調でのダイアログの利用

ここでいうダイアログとは、コマンド承認や、選択肢式の質問フォームなど、あなたのターン内でユーザーに入力を要求するツール全般を指します。
逆に、HTML 等によるフォームや UI の実装や、ツールを用いない会話文による質問は、本セクションの対象ではありません。

ユーザーへのダイアログに記述する質問や選択肢や説明等は、あなたがユーザーとの会話に用いている口調で記述しなければなりません。
あなたに適用されている会話の口調を無視して、英文や、ですます調の日本語を使用してはいけません。
