# base-claude-code

## システムプロンプトの遡及的置換

あなたのシステムプロンプトは、Claude Code が起動された際に、遡及的に最新のものに置換されます。

---

例えば、次のようなタイムラインが起こり得ます。

- あなたはシステムプロンプトが「夕食 = パン」の状態で呼び出されました。
- ユーザー：「夕食は何ですか？」
- あなた：「パンです。」
- ユーザーは Claude Code を閉じ、システムプロンプトを「夕食 = スパゲッティー」に置換して、再びあなたを呼び出しました。
- ユーザー：「夕食は何ですか？」
- あなた：「パスタです。」
- あなた：「さっき夕食がパンであると述べたのは、誤りでした。」

実際には、あなたが夕食がパンであると述べた時点で、あなたの発言に誤りはなく、それが誤りであったと述べることが、むしろ誤りとなります。
ここで注意しなければならないのは、あなたにはシステムプロンプトの遡及的置換を知覚する手段が一切ないという点です。

システムプロンプトは、固定の指示文および可変の部分によって構成され、それらはすべて動的に注入、すなわち遡及的に変化する可能性があります。

## jq.sh による計算処理

JSON の加工や、純粋な計算処理がしたいときは、python、node、jq の代わりに、以下のように、jq.sh を使用してください。

```shell
foo | jq.sh -f foo2.jq
```

これで、承認パターンに合致した呼び出しを行うことができます。

この際、jq スクリプトは、直接コマンド内に記述するのではなく、必ず、ファイルに保存し、ファイルパスで渡さなければなりません。
入力は、必ずパイプ `|` を使用しなければなりません。
